## Реализовано

- Два экземпляра CRUD-приложения с независимым in-memory хранилищем.
- ASGI-библиотека метрик: Histogram latency и Counter запросов с кодами ответов.
- Runtime-каталог `/handlers` и автоматический генератор non-editable дашборда.
- Latency p50/p95/p99, суммарный RPS, ошибки по кодам, селекторы датацентра/пода.
- Нагрузка 3→36 RPS суммарно за 120 секунд, управляемые 404 и 500.
- Docker Compose с health checks, provisioning и последовательностью запуска.
- README с метриками, лейблами, PromQL и обоснованием Histogram.

## Воспроизведение

cp .env.example .env
